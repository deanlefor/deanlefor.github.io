Privacy and your data

Updated September 6, 2026

The retirement planner, PhD tracker, run tracker and scorecards save your inputs in your browser. They do not upload saved records to an application database, and the website owner cannot recover them for you.

Saved on this device

Other people using the same browser profile can access saved records. Pages on the same website origin share browser storage, so scripts running on this site can also access it. These tools do not encrypt records or provide a separate private account.

Clearing this site's browser data removes locally saved records. Private browsing usually removes them when that session ends. If saving is blocked or storage is full, follow the tool's warning and export a backup before closing the page.

Sharing and exports

The PhD tracker lets you preview a snapshot before copying a share link. Name and email are excluded by default; you can choose to include them. Custom course names and the plan itself may still identify you.

Anyone with the full link can read, forward and retain that snapshot. The link uses reversible encoding, not encryption. It has no sign-in, expiry or revocation. Editing or resetting your tracker does not remove earlier links or copies. The portion after #view= is not sent in the normal page request, but recipients and services where you paste the full link receive it.

Use Print summary (no profile) when credit totals, DMP count and start semester are sufficient. The full PDF report includes your name, email and detailed plan. Review any report before sharing it.

JSON exports may contain names, financial inputs, academic plans, run notes or game participants. Keep recovery backups in a private location outside this public website repository. Share only the information the recipient needs. To clear all records from these tools, remove this site's data using your browser settings; this does not erase downloaded files or shared copies.

Website and resource requests

GitHub Pages hosts the site and receives ordinary web requests, including connection information such as your IP address. Some pages load fonts from Google or icon fonts from jsDelivr; the run tracker loads map tiles from OpenStreetMap. Map image requests include the website origin as the referrer, as required by that provider, but do not include the page path or share-link fragment. These providers receive the requests needed to supply those resources. The tools do not include saved planning records in those resource requests.

The run map shows a fixed virtual North Dakota route. It does not request your GPS location. The site includes no analytics or advertising scripts. Leaflet, the map's JavaScript library, is served with this site's own files.

Links to other websites follow those sites' own practices. For a privacy question, use the website contact address; avoid sending financial inputs or private backup files.
