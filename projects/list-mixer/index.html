A small guide to List Mixer

1. Build your library

Create named lists and paste one item per line. Import TXT files or choose a column from a CSV file. Commas inside an item stay part of that item. Bulk imports are previewed before being added to the editor. Clean up removes blank lines, bullet-only lines, outer spaces, and leading list bullets such as “- ”, “* ”, or “•”. It keeps item order and repeated items; use Remove duplicates separately. Signs in values such as -5 and punctuation inside items stay intact. Review the draft; Save list commits your changes.

Link a category to a sub-list

Create your model lists first, such as Car models and SUV models. Then create a parent list with Car and SUV as its items. In its editor, expand Linked sub-lists, choose an item and its matching library list, and click Add link. Save list keeps the links. Check only the parent list in your setup; linked lists are used even when unchecked. In the library, Parent labels name their sub-lists and Sub-list labels name their parents. Expand a label for the exact item-to-list connections. “Automatic through parent” means a checked parent will use that sub-list when its matching item is chosen. If both are checked, “Extra draw selected” and a notice explain the extra independent draw. Uncheck linked sub-lists fixes all such overlaps in the current setup, including lists hidden by search or Selected. Positions, draw counts, current output, and favorites stay unchanged; direct locks on unchecked sub-lists are released. Undo restores the selections and locks. You can keep both checked when an extra draw is intentional. Generate picks the category first, then one matching item: “Car, BMW M3”. Include list names keeps each pair on one line, such as “Vehicles: Car, BMW M3”.

One level is supported: sub-lists cannot have links of their own. Ordinary unlinked items still work. Category odds depend on the parent entries, not on how many models each sub-list contains. Duplicate entries still add weight. Draw counts choose distinct parent items; each gets one child, and different categories may draw the same child value. Checking a sub-list separately adds a separate independent draw. Locks keep the category and child together. Removing either value or changing the link releases that lock. Links match exact item text; after renaming an item, reconnect its link. Deleting a sub-list removes its links but keeps the parent items. Undo restores the deletion. Duplicating a parent copies its links to the same shared sub-lists. All links and locked pairs are included in backups; importing copies reconnects them to the imported sub-lists. Existing favorites and recent results keep their exact saved output.

2. Make a setup

A setup remembers which shared lists are checked, all list positions, each Draw count, and your instructions. Unchecking a list keeps it in place, and rechecking restores its position in the output. Use All to see the full library or Selected to hide unchecked lists. Hiding lists never changes their saved positions or selections. Drag the grip beside a list to reorder it; a line shows where it will land. When filtering by Selected or search, only visible lists exchange positions and hidden lists stay in their exact saved slots. Click the grip to choose a position, or focus it and use Arrow Up, Arrow Down, Home, or End. Escape cancels a drag. Compact rows keep items in the Edit dialog. Each setup remembers its own All/Selected choice when you switch setups, refresh, or reopen the page. New setups start with All; duplicates copy the original setup’s choice. The choice is included in backups alongside list positions. On upgrade, existing setups inherit your previously saved browser preference. Search resets on reload. New lists appear at the end. Editing a shared list updates it for every setup. Duplicate a list when you want an independent variation.

3. Mix

Choose a Draw count beside each list. Generate chooses that many distinct values from each checked list, including any locked picks. Counts and positions are saved per setup and included in backups. Changes to counts and checked lists apply on the next Generate. If a list has too few distinct items, lower its count or add more items. With Include list names off, items are comma-separated. Turn it on for one “List name: item” per line. An empty checked list must be filled or unchecked. Formatting changes keep your current random picks.

Place and reuse instructions

The setup note can appear at the Beginning or End. Create named reusable instruction blocks, check the ones to include, and choose Beginning or End for each. Arrows order checked blocks within each position. The setup note comes first in its position; instruction blocks keep their wording and line breaks, with a blank line between sections. Selections and positions belong to each setup; block text is shared. Duplicate a block for an independent variation. Editing instructions updates existing results without rerolling their random items.

Keep picks and save good results

After generating, click Lock beside a pick to keep it when you generate again. Unlock it to allow new choices, or use Unlock all. Locks belong to each setup and survive reloads. Unchecking a list, deleting it, or removing its locked item releases that lock. When a list draws multiple items, each pick can be locked separately and keeps its output position. Lowering a Draw count releases locks in the removed positions. Older saved results may need one fresh generation before they can be locked.

Recent results & favorites keeps the latest 50 generated results across all setups. View or copy any result, or star it as a favorite. Favorites are separate, exact copies of the output and stay saved until you remove them, even if a list or setup is deleted. Changing instructions or formatting updates only the current result; saved history and favorites keep their original wording. In Favorites, click Rename to add or change an optional name. Names appear above the picked items and in the full view. They are included in backups; copying a result copies only its original output. Leave the name blank to remove it. You can keep up to 500 favorites. Clearing recent results keeps favorites; removal and clearing offer Undo.

How random is it?

List Mixer uses your browser’s cryptographic random-number generator with unbiased selection. New picks use unbiased random selection among the remaining entries. A value appears at most once per list in a result; different lists draw independently. Locked picks stay fixed and count toward the requested total. Repeats across generated results are normal. Duplicate entries increase that value’s chance of being selected; use Remove duplicates if you want each distinct value to have equal odds.

Saving & moving between computers

Edits save automatically in this browser. Changes in the list editor are drafts until you press Save list. Export backup downloads all lists, reusable instruction blocks, setup notes, formatting choices, locks, remembered list positions, All/Selected choices, draw counts, recent results, favorites and their names, and the last results. Version 1 backups still import with the original comma-separated output and instructions at the end. Version 2, 3, and 4 backups also import; older favorites start unnamed, list order starts from the current display order, and Draw defaults to 1. Version 5 backups also import. Backups from versions 1–5 start with All because they did not store a view per setup. Version 6 backups retain each setup’s view. New backups use version 7 and include links and locked pairs; app version 1.8 or later can read them. Open the updated app when moving data between browsers. Import backup can add copies or replace the library, with an undo option.

Browser data is not a backup: clearing browser data, using a private window, moving this HTML file, or switching browsers may make saved lists unavailable. Export regularly and before moving the app. If storage is blocked or full, an alert appears and you can still export your work.

Entirely self-contained

This HTML file has no external dependencies, accounts, tracking, or network requests. Open it in a modern browser on Windows or Mac. Nothing needs to be installed.
