A small guide to List Mixer

1. Build your library

Create named lists and paste one item per line. Import TXT files or choose a column from a CSV file. Commas inside an item stay part of that item. Bulk imports are previewed before being added to the editor. Clean up removes blank lines, bullet-only lines, outer spaces, and leading list bullets such as “- ”, “* ”, or “•”. It keeps item order and repeated items; use Remove duplicates separately. Signs in values such as -5 and punctuation inside items stay intact. Review the draft; Save list commits your changes.

2. Make a setup

A setup remembers which shared lists are checked, their order, and your instructions. Use the arrows beside checked lists to change output order. Editing a shared list updates it for every setup. Duplicate a list when you want an independent variation.

3. Mix

Generate chooses one entry from every checked list. With Include list names off, items are comma-separated. Turn it on for one “List name: item” per line. An empty checked list must be filled or unchecked. Formatting changes keep your current random picks.

Place and reuse instructions

The setup note can appear at the Beginning or End. Create named reusable instruction blocks, check the ones to include, and choose Beginning or End for each. Arrows order checked blocks within each position. The setup note comes first in its position; instruction blocks keep their wording and line breaks, with a blank line between sections. Selections and positions belong to each setup; block text is shared. Duplicate a block for an independent variation. Editing instructions updates existing results without rerolling their random items.

Keep picks and save good results

After generating, click Lock beside a pick to keep it when you generate again. Unlock it to allow new choices, or use Unlock all. Locks belong to each setup and survive reloads. Unchecking a list, deleting it, or removing its locked item releases that lock. Older saved results may need one fresh generation before they can be locked.

Recent results & favorites keeps the latest 50 generated results across all setups. View or copy any result, or star it as a favorite. Favorites are separate, exact copies of the output and stay saved until you remove them, even if a list or setup is deleted. Changing instructions or formatting updates only the current result; saved history and favorites keep their original wording. In Favorites, click Rename to add or change an optional name. Names appear above the picked items and in the full view. They are included in backups; copying a result copies only its original output. Leave the name blank to remove it. You can keep up to 500 favorites. Clearing recent results keeps favorites; removal and clearing offer Undo.

How random is it?

List Mixer uses your browser’s cryptographic random-number generator with unbiased selection. Every entry in an unlocked list has equal odds and each new pick is independent. Locked picks stay fixed. Repeats are normal. Duplicate entries increase that value’s odds; use Remove duplicates if you want each distinct value to have equal odds.

Saving & moving between computers

Edits save automatically in this browser. Changes in the list editor are drafts until you press Save list. Export backup downloads all lists, reusable instruction blocks, setup notes, formatting choices, locks, recent results, favorites and their names, and the last results. Version 1 backups still import with the original comma-separated output and instructions at the end. Version 2 and 3 backups also import unchanged; older favorites start unnamed. New backups use version 4; older app versions cannot read them. Open the updated app when moving data between browsers. Import backup can add copies or replace the library, with an undo option.

Browser data is not a backup: clearing browser data, using a private window, moving this HTML file, or switching browsers may make saved lists unavailable. Export regularly and before moving the app. If storage is blocked or full, an alert appears and you can still export your work.

Entirely self-contained

This HTML file has no external dependencies, accounts, tracking, or network requests. Open it in a modern browser on Windows or Mac. Nothing needs to be installed.
