Important

How offline works

Install the app from Safari using Share → Add to Home Screen. Visit and load it while online first. Thereafter, a cached version can open offline.

Browser storage is still removable when the website is deleted or its data is cleared. Keep independent backup files.

There is no automatic cloud synchronization or payment connection.
